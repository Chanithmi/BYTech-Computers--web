Website Features:

Header section displays the shop name "ByteTech Computers" and its tagline.
Welcome section introduces the computer shop.
Products section displays three product categories: Laptops, Desktop Computers, and Accessories.
Product cards include images, titles, and short descriptions.
Special offer section displays a 15% weekend discount on selected accessories.
Contact section provides the shop's address, telephone number, and email address.
Footer displays copyright information.
Responsive layout using Bootstrap to support different screen sizes.

Images:
Product images of laptops, desktop computers, and computer accessories are used in the webpage. The images are loaded from online image sources.
